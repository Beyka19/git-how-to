# Как работать с ветками

Ветка в Git — это указатель на коммит.
Создать ветку: git branch <имя>.
Переключиться: git checkout <имя>.
Полная инструкция

Создать ветку:
    git branch <имя>

Переключиться в ветку:
    git checkout <имя>

Создать и сразу переключиться:
    git checkout -b <имя>

Отправить ветку на сервер:
    git push -u origin <имя>
